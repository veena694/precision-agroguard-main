# Precision AgroGuard

Precision AgroGuard is an AI-powered crop disease detection and automated spraying system.

## Features
- Real-time disease analysis using an ensemble of 5 ONNX models.
- Automated spraying control via ESP32 integration.
- Full-stack React + Express architecture.
- Deployed on Hugging Face Spaces using Docker.

## Tech Stack
- **Frontend**: React, TailwindCSS, Lucide Icons.
- **Backend**: Node.js, Express, Sharp, ONNX Runtime.
- **Models**: DeiT, EfficientNet, Hybrid, MaxViT, ViT.
